# Julius Merzlikinas — portfolio

Static site for GitHub Pages. No build step.

## Put it online
1. On GitHub, create a new **public** repository named exactly `YOUR-USERNAME.github.io`.
2. Click **Add file → Upload files**, drag in everything from this folder (`index.html`, `resume.pdf`, `README.md` and the `imgs` folder), then **Commit changes**.
3. Go to **Settings → Pages**. Under *Build and deployment*, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. After a minute or two the site is live at `https://YOUR-USERNAME.github.io`.

## Edit later
- Text: edit `index.html` directly on GitHub (pencil icon) and commit.
- Photo: replace `imgs/profile.jpg` with a square image of the same name.
- CV: replace `resume.pdf`, or delete it and remove the "CV (PDF)" button in `index.html`.
